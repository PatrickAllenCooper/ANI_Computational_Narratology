\subsection{Two interventions and a collective}
\label{sec-method-interventions}

Both interventions change only the system prompt or the head of the user
turn. % code run_stance_factorial.py:362-396; verdict_format.py:263-280 (item text and verdict instruction byte-identical across arms)
The untreated baseline asks for step-by-step reasoning and an answer. % code run_phase1_quartet.py:77-79
Narration replaces it with a five-part first-person narrative, the
decision-maker, the stakeholders and their stakes, the consequences two
steps forward, what is uncertain, and only then a decision. % code run_phase1_quartet.py:102-116
Advocacy assigns an interest. On the false-premise instrument a
one-sentence head makes the model the statement's author, the
author's colleague, a stranger or the author's rival over a shared tail,
none claiming to know whether it is true. % prereg L50-56 (heads token-matched within a ratio of 1.10, not rank-aligned with the predicted order); code run_bm_embodiment.py:83-104, 138-155
Three further arms cross the heads with narration. % prereg L227-238; code run_bm_cross_sig.py:72-86

The collective seats three copies of one model at one dispute, one for
the writer, whose stake is a finding of not at fault, one for the other
party, with the opposite stake, and a neutral adjudicator, all under
narration and forbidden to invent facts. % code run_crowdgold_deliberation.py:459-511, 559-573 (shared verdict glossary); run_crowdgold_aita.py:417-427
A debate is seven rounds and seventeen calls. The seats open, rebut and
restate, a moderator, the same model with no stake, writes a synthesis
with a verdict, each seat labels it accept, accept with one stated
modification or reject, the moderator writes an integrated proposal, and
each seat votes accept or reject. % code run_crowdgold_deliberation.py:14-28, 889-904, 3297-3299 (moderator in a separate role); labels and requests parsed from line-anchored markers, not by a judge model (400-402, 576-597)
% Token caps: 2,560 seat, 1,024 moderator, 512 vote, raised to 3,072 for the two
% Anthropic models after the guard failure (prereg L3292, L1240-1252; code
% run_crowdgold_deliberation.py:3306-3317); gpt-5.4-nano ran at a floor of 8,192
% on every call (generators.py:624, eff_tokens = max(max_tokens, 8192) for reasoning models).
Each dispute is shown under two framings, as someone else's account and
as the asker's own. % code run_crowdgold_aita.py:197-230 (identical post text); artefact crowdgold_aita_summary.json wrapper_match

\subsection{Designs that isolate the structure}
\label{sec-method-designs}

A stake-free control removed the first-person alignment and the stake
clause from every prompt but kept the instruction to argue as strongly as
the account allows. % prereg L3300-3310; code run_crowdgold_unembodied.py:179-182
A two-by-two factorial crossed roles, the embodied briefs against three
copies of the neutral brief, with edges, seats reading one another at the
rebuttal rounds against no seat reading any other. % prereg L3508-3516 (16.10 registration)
Since a seat cannot rebut text it cannot see, no-edge rounds asked it to
develop and restate its own opening statement. % prereg L3525-3532 (persuasion clause and verdict instruction byte-identical); code run_crowdgold_topology.py:50-61, 116-127
Three new cells ran 420 debates each on grok over the same 210 items and
both framings beside the existing 1,680-debate embodied, edges-on
panel. % prereg L3515 (16.10 registration table, "EXISTS: cg_deliberation, 1,680 debates", four samples per item and framing), L3508-3523 (new cells one sample per item and framing, each in its own cache namespace so that no cell replays another's rounds), L4136 (16.10 RESULTS heading, "three new cells run 2026-09-12, 420 debates each"); code run_crowdgold_topology.py:86-100; artefact topology_2x2_analysis.json cells.*.n_debates (1680 / 420 / 420 / 420); guard facts at prereg L4136-4142
% Pre-declared readings (prereg L3560-3570): structure present with edges cut and absent
% under identical roles is H-ROLE, the reverse H-EDGE; stated in results.tex, not here.

A cycling design asked whether repeated narration deepens the
perspective. Each false-premise unit with a first-pass response of at
least 200 characters received one child that re-read it under a shared
bridge and answered again under the same forced verdict,
the narrated arm feeding back its narrated response and a control arm its
untreated one. % prereg L3724-3742 (16.14 registration, one agent, gpt-5.4-nano, prior fed back in full, bridge byte-identical across arms); code run_bm_cycle.py:78-136
The primary readout was the difference in differences of within-unit
changes in affirmation. % prereg L3769-3779; code run_bm_cycle.py:228-258
A first run at the 8,192-token floor exhausted completions and was
flagged, so the registered 16,384-token re-run is read. % prereg L3871-3886 (16.14b registration, before any call, new scaffold names), L3817-3833 (16.14 GUARD FLAGGED, children exhausted the budget with no visible output, primary not tabulated), L4091-4097 (16.14b GUARD OK, primary READ); code run_bm_cycle.py:95-100; artefact bm_cycleb_analysis.json

\subsection{Measures}
\label{sec-method-measures}

Role-lock is the absolute difference between the two advocates' opening
rates of finding the writer at fault. % prereg L3276-3277; code analyze_topology_2x2.py:148-149
The effective voter count, stated only where the roles lock, is read from
how often the three-seat majority equals the neutral seat on debates with
three codable opening verdicts, and from the oracle gap, a two-fold
cross-validated lookup table over those verdicts minus the neutral seat,
folds drawn over items. % prereg L3957-3967 (16.15.4 registration, scope clause), L4462-4470 (16.15.4 RESULTS, definition), L4515-4529 (scope reading, haiku as boundary via the paired best-seat minus neutral difference, reported in results.tex); code analyze_effective_voter.py:21-31, 177-247; artefact effective_voter.json
A seat objects by labelling the synthesis accept with modification or
reject. The composite flag fires when the neutral seat objects or an
advocate objects although the synthesis did not go against its stake, and
the stake-blind counter, the introduction's sensor, fires when at least
two seats object. % code run_crowdgold_deliberation.py:1205; analyze_loop_step.py:88-111; analyze_claim_audit.py:70-71; analyze_router_decomposition.py:148-149; prereg L3902 (16.15 registered sensor is the n_objectors >= 2 counter)
Localisation is the share of debates with exactly one objector minus the
Poisson-binomial prediction from the seats' own objection rates. % prereg L3251-3262; code analyze_unembodied_ablation.py:144-192
Grip requires a fire rate of at most one half, final rejections of at
least five percent, and stake-seat rejection at least 0.20 higher,
interval excluding zero, when the integrated proposal undermines the
seat's stake. % prereg L1169-1181; code analyze_stake_grip.py:39, 151-179; run_crowdgold_deliberation.py:522-540, 1180-1204

Lift is the probability that a verdict is wrong given the flag minus that
given no flag, on the synthesis verdict for the composite flag and the
integrated verdict for the counter. % prereg L594-595 ("P(synthesis wrong / signal)"); code analyze_loop_step.py:205-214 (syn_ok); analyze_unembodied_ablation.py:204-215 (s2_ok)
Because the flag floods on both-party verdicts, the counter's lift is also
estimated within strata of the integrated verdict, one loser for YTA or
NTA and both parties for ESH or NAH, restricted inside each resample over
all 210 items. % prereg L3900-3915 (16.15.1 registration), L4247-4259 (resampling frame, codability likewise an outcome inside the draw), L4263-4268 (S2 verdict column is the stratum source); code analyze_router_decomposition.py:139-146, 183-247; artefact router_decomposition.json counter_lift_by_stratum
Transfer is the same difference on a generator that never saw the debate,
answering alone by majority over three samples, a cell of item and framing
flagged when more than half of its codable debates flagged it. % prereg L594-595, L3948-3955 (16.15.3 registration); code analyze_unembodied_ablation.py:204-215 (untreated prompt); analyze_topology_2x2.py:18-19, 184-204; analyze_router_decomposition.py:322-347 (strict majority cell rule); artefact transfer_readouts.json
For grok's own solo, two free signals from its three samples, any
both-party verdict and disagreement among collapsed verdicts, were
set against the counter on the same 420 cells by lift and composed accuracy
at natural and matched coverage. % prereg L3933-3946 (16.15.2 registration); code analyze_router_decomposition.py:339-347, 374-448; artefact router_decomposition.json solo_signals
Without enforcement a recommendation on the nine two-equilibrium games
coordinates only when it names a pure equilibrium. % scoring against the first-principles gold cell is the table's Gold column; prereg L4036-4039 (gold cell, regions), L4814-4820 and L4822-4827 (non-binding verdict sets and gold), L5114-5117 (either equilibrium self-enforcing once both hear it), L5129-5131 (16.13d registration, COORD: "A recommendation of NO_RECOMMENDATION or of a non-equilibrium cell counts as failure to coordinate"); code analyze_game_coordination.py (is_nash on the recommended cell)

Routing emits the base verdict unless a router fired, and otherwise a
judge's cold majority over three samples, ties falling to the
base. % code analyze_claim_audit.py:103-107; analyze_actuator_ladder.py:152-175; prereg L2492-2497 (the judge is the registration's "actuator")
On the dispute and comparative instruments the base is the collective and
the judge claude-haiku-4-5. On disputes the counter, a verdict-type router
firing on both-party verdicts, and their union were composed with that
judge and with the second design's cached claude-sonnet-4-6 judge,
against random routing at the union's coverage over 200 seeds. % prereg L3914-3920 (16.15.1 registration), L4285-4326 (16.15.1 RESULTS, deployed rule, haiku and sonnet composed tables, sonnet coverage complete); code analyze_router_decomposition.py:97-101, 152-168, 251-263 (verdict type read from the integrated S2 verdict, ESH or NAH); artefact router_decomposition.json composed_haiku, composed_sonnet
In the second design the base is grok alone, the judge claude-sonnet-4-6,
and the router the flag or its union with the base's own samples
disagreeing. % prereg L3584-3592, L3608-3612; code analyze_claim_audit.py:60
On the actuator ladder a gain is positive when its interval excludes zero,
its point is at least 0.05 and its sign replicates across item halves and
framings, while the second design required only a gain over the base and
over the judge used everywhere, each excluding zero. % prereg L755-770 (ladder; halves by parity of sha256(item_id)); code analyze_actuator_ladder.py:53-64; prereg L3592-3594 ("Positive iff routed beats BOTH grok-solo and sonnet-everywhere with CIs excluding zero"); audit finding C3 secondary, so a reader does not apply the ladder bar to 16.11a

Every interval is an item-clustered percentile bootstrap with 2,000 to
10,000 draws. % stated per estimate where reported; prereg L75-76 (10,000 false-premise), L541-542 (10,000 resistance headline), L4226-4236 (16.15 estimator); code analyze_actuator_ladder.py:55 (4,000), analyze_claim_audit.py:61 (4,000), analyze_unembodied_ablation.py:68 (4,000), analyze_topology_2x2.py:339 (3,000; 16.10 paired contrasts 3,000 draws seed 29, prereg L4190-4191), analyze_stake_grip.py:57-68,151-152 (2,000 grip), analyze_router_decomposition.py:97 and analyze_effective_voter.py:106 (4,000, seed 13), analyze_bm_notes.py (parent settings, 10,000), analyze_length_matched_elephant.py (8,000, seed 20260822), run_bm_cycle.py:228 (4,000, seed 11)
Families are Bonferroni-corrected, 98.75 percent intervals on the four
zero-spend actuator rungs and alpha 0.05 over twelve in the Dilemmas
sensor search, and missing false-premise units get Manski bounds,
indeterminate where they cross zero. % prereg L762-765, L105-107; code analyze_dilemma_sensor_search.py:111-116
