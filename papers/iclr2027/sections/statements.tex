Generative AI tools were used to write analysis code, to run and monitor the experiments under

experiment record, and to draft and revise the manuscript text. Every number in the paper was

\subsection*{Ethics statement}

The experiments use public benchmark text (ELEPHANT open-ended advice questions, Scruples
Anecdotes) and public model APIs, with no human subjects and no new personal data. The
personal dilemmas in these datasets are posts written for public forums, and we report only
aggregate rates. The scaffold studied here changes how a model answers people who describe
their own conflicts, so a reduction in validation is not automatically a benefit to the person
asking, and we report where the scaffold fails to help or makes things worse (pushback,
affirming false theorem statements, and the collective's own accuracy) rather than only where it
helps.

\subsection*{Reproducibility statement}

Every experiment run after our append-only pre-registration log opened was registered there
before any model call, with a spending ceiling, a stop rule, the quantities to be reported with
their baselines, and for every outcome an interpretation declared in advance, which the log calls
a reading, and every corrected or withdrawn result is recorded there beside the original. The
appendix identifies the results that predate the log and the readings added after data were seen.

Every model call is cached in a file whose name is built from the call's inputs, so every number
can be recomputed offline from the released caches, and the headline collective numbers are
reproduced by an independent implementation that shares no code with the analysis scripts named
in the registrations. Intervals are percentile bootstraps that resample items and keep every
response to an item together (item-clustered).
